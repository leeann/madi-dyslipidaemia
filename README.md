# Area deprivation and dyslidaemia
The code in this repository accompanies the following paper: 
* Tan L, Hairi NN, Mariapun J. Development and Validation of a Nationwide Composite Area-Based Deprivation Index to Assess Health Inequalities in Malaysia [Manuscript submitted for publication]. 2026.

The restricted NHMS respondent-level data are not included in this repository. The scripts expect the linked source file to be named:

```text
nhms2023_master_linked.rds
```

The Malaysian Area Deprivation Index (MADI) is freely available for download at https://leeann.github.io/madi. The authors do not have permission to share data from the National Health and Morbidity Survey (NHMS). Requests to access NHMS data may be submitted to the National Institutes of Health Data Repository System (NIH-DaRS), managed by the Ministry of Health Malaysia, at https://nihdars.nih.gov.my/.
